# Data sources: food nutrition

The food catalog lives in `data/foods/foods.json` and is loaded into
`public.foods` by migration `012_seed_foods.sql` (generated by
`node scripts/foods/build-seed.ts`).

## What comes from where

- **Legacy fields** (kcal, protein, carbs, fat, packs, reference prices, names,
  tags): copied unchanged from `supabase/functions/_shared/catalog.ts`. The
  catalog stays the reference for these values.
- **Extended fields** (fiber, free sugars, saturated fat, sodium, iron): per 100 g
  (or 100 ml), filled by `scripts/foods/fetch-nutrition.ts` from the sources
  below, then rounded to the table precision and capped to the legacy macros
  (fiber and free sugars never exceed carbs, saturated fat never exceeds fat).
  The builder logs every cap it applies.

## USDA FoodData Central

- License: public domain (CC0 1.0). Link: <https://fdc.nal.usda.gov/>
- Used: 67 foods, one FDC id each (`nutritionRef` in `foods.json`), mostly from
  SR Legacy (bulk download `FoodData_Central_sr_legacy_food_json_2018-04`).
  `tomate_arbol` uses FDC 1906026 (tamarillo, branded record) because SR Legacy
  has no tamarillo.
- Substitutions: `leche_deslactosada` uses plain whole milk (FDC 171265), whose
  values for these fields match lactose-free milk.
- Free sugars rule: `none` for whole foods (0), `all` (total sugars) for sugar,
  panela and honey, `added` (added sugars, or total sugars if the source has no
  added sugars) for processed foods (`pan_tajado`, `pasta`, `harina_maiz`).

## Open Food Facts

- License: Open Database License (ODbL) 1.0 for the database, DbCL for its
  contents. Link: <https://world.openfoodfacts.org/> and
  <https://opendatacommons.org/licenses/odbl/1-0/>
- Attribution: nutrition data from Open Food Facts contributors.
- Products used (barcodes of products sold in Colombia):

| Food | Barcode | Product |
| --- | --- | --- |
| `harina_maiz` | 7702020212021 | Harina de Maíz Amarillo Extrafina (Doñarepa) |
| `pan_tajado` | 7705326468727 | Pan Blanco Tajado (Bimbo) |
| `panela` | 7709027205407 | Panela Orgánica (Waiva) |

Requests to Open Food Facts send the identifying user agent from
`scripts/prices/policy.json` and wait one second between calls.

## Not used

- **Colombian Food Composition Table (TCAC, ICBF):** not used until we have
  written permission from ICBF.

## Re-running

```sh
# Fill the extended fields (USDA_API_KEY is optional; DEMO_KEY is ~10 requests/hour,
# so pass the official SR Legacy JSON to avoid the API for most foods)
node --max-old-space-size=4096 scripts/foods/fetch-nutrition.ts --usda-dump <SR Legacy json>
# Regenerate the migration
node scripts/foods/build-seed.ts
```

Tests never use the network: they run against the fixtures in
`scripts/foods/fixtures/`.

## Wholesale reference prices: DANE SIPSA

Fuente: Departamento Administrativo Nacional de Estadística: www.dane.gov.co
(SIPSA, Sistema de Información de Precios y Abastecimiento del Sector
Agropecuario). DANE's terms of use
(<https://www.dane.gov.co/index.php/terminos-y-condiciones>) allow use,
transformation and analysis of its data with that literal citation, and DANE
is not responsible for how third parties use or interpret it: our
"Aproximado" prices are our own calculations, not official DANE figures, and
the app says so. Public, official data from the Colombian statistics office,
read through its public SOAP web service
(`https://appweb.dane.gov.co/sipsaWS/SrvSipsaUpraBeanService`, SOAP 1.2,
operation `promediosSipsaSemanaMadr`; guide:
<https://www.dane.gov.co/index.php/estadisticas-por-tema/agropecuario/sistema-de-informacion-de-precios-sipsa/servicio-web-para-consulta-de-la-base-de-datos-de-sipsa>).

- Market used: **Bucaramanga, Centroabastos**, weekly average wholesale price
  (COP per kg; eggs per unit).
- One request per week (`.github/workflows/prices-weekly.yml`, same protected
  `prices` environment). The service answers with the whole history (about
  66 MB); only the rows of that one market are kept.
- `scripts/prices/dane/mapping.json` links SIPSA product codes to our foods
  (49 of 70 foods; meat, dairy, bread and other foods SIPSA does not publish
  for this market keep the static reference price).
- Wholesale is converted to our base unit, multiplied by a documented retail
  markup (`scripts/prices/dane/markup.ts`, approximations) and stored in
  `city_reference_prices` only if it lies within x0.33 to x3 of the food's static
  reference price; otherwise it is reported as an anomaly and skipped.
- The planner uses it only as the base of **estimated** prices (shown as
  "Aproximado") when it is at most 45 days old; real store prices win over it.
- Attribution is shown in the privacy policy ("Fuentes de datos", es/en) with
  the same literal citation (checked by `scripts/prices/dane/attribution.test.mjs`).

Evidence behind the retail markups (2026-11-04 review; still approximations):

- Packaged staples (`abarrotes` 1.15): DANE, Encuesta Anual de Comercio 2013,
  cost/sales ratio of supermarkets ("no especializados con surtido
  principalmente de alimentos", CIIU 4711) = 86.5%, i.e. sales = 1.156 x cost
  (<https://www.dane.gov.co/files/investigaciones/boletines/eac/bol_eac_2013.pdf>).
- Fresh produce (`fresco` 1.35): CCI (2002) and Cámara de Comercio de Bogotá
  (2004), cited by Parrado & Montoya, Agronomía Colombiana 25(2) 377-382, 2007:
  supermarket margin on fruit and vegetables 35-45%, neighbourhood shop 30-40%
  (<https://distantreader.org/stacks/journals/agrocol/agrocol-14143.pdf>).
  1.35 is the low end of that range.
- Eggs and fish (`proteina` 1.20): no official margin found; our shelf samples
  of eggs (data/price-samples) sit at 1.0-1.34 x the Centroabastos price.

Re-running (reads the network; `--dry-run` writes nothing and needs no secrets):

```sh
node scripts/prices/dane/main.ts --dry-run
```

Tests never use the network: they run against `scripts/prices/dane/fixtures/`
(a trimmed copy of a real answer captured 2026-11-04; the "Pera importada"
rows, code 141, were added from the same answer when pera was remapped).

### Static reference prices vs DANE (review of 2026-11-04)

Every static `refPriceCop` of the 49 mapped foods was compared with DANE
SIPSA (Bucaramanga, Centroabastos, week of 2026-10-24) x the retail markup.
The owner approved these changes (`data/foods/foods.json`, the planner
catalog `supabase/functions/_shared/catalog.ts`, the regenerated seed 012 and
migration `014_fix_reference_prices.sql` for databases that already ran 012):

| Food | Before | Now | Why |
|---|---|---|---|
| cebolla_junca | 10.9 (sample) | 2.7 (estimate) | SIPSA yearly median 1,975 COP/kg x 1.35 |
| cilantro | 41.8 (sample) | 9.5 (estimate) | SIPSA yearly median 7,071 COP/kg x 1.35 |
| lechuga | 8 | 4 | near DANE x markup (3.09) |
| pepino | 8 | 3.5 | near DANE x markup (2.90) |
| ajo | 20 | 11 | near DANE x markup (8.26), sold in small mesh bags |
| repollo | 3 | 1.8 | near DANE x markup (1.40) |
| remolacha | 4 | 2.5 | near DANE x markup (1.59) |
| calabacin | 6 | 3 | near DANE x markup (2.70) |
| espinaca | 12 | 8 | near DANE x markup (6.49) |
| naranja | 800 / unit | 450 / unit | near DANE x markup (331) |
| aguacate | 3500 / unit | 2500 / unit | near DANE x markup (2,081) |
| guayaba | 6 | 4.5 | near DANE x markup (3.49) |
| tilapia | 25 | 17 | near DANE x markup (13.9) |
| sardina_lata | 36 | 25 | near DANE x markup (22.4) |

COP per g unless marked. The old cebolla junca and cilantro values were a
packaged-herb shelf price read outside Bucaramanga (the crossed-out price
during a 40% promotion), 4-6x above DANE, so the weekly job rejected DANE for
them every week. The yearly median (the 50 weekly prices of the last year in the service's answer) is used
for both because their wholesale price swings a lot (cilantro 2,625-14,357
COP/kg in the year). `pera` keeps 1800 per unit but is now mapped to SIPSA 141
"Pera importada" (the catalog pear, 170 g), not 142 "Pera nacional".
banano, papa and zanahoria stay as real shelf samples although they sit at
x1.65-x1.73. `scripts/prices/dane/referencePrices.test.mjs` keeps every other
mapped food within x0.6-x1.6 of DANE x markup on the fixture week.
