# Data sources: food nutrition

The food catalog lives in `data/foods/foods.json` and is loaded into
`public.foods` by migration `012_seed_foods.sql` (generated by
`node scripts/foods/build-seed.ts`).

## What comes from where

- **Legacy fields** (kcal, protein, carbs, fat, packs, reference prices, names,
  tags): copied unchanged from `supabase/functions/_shared/catalog.ts`. The
  catalog stays the reference for these values.
- **Extended fields** (fiber, free sugars, saturated fat, sodium, iron): per 100 g
  (or 100 ml), filled by `scripts/foods/fetch-nutrition.ts` from the sources
  below, then rounded to the table precision and capped to the legacy macros
  (fiber and free sugars never exceed carbs, saturated fat never exceeds fat).
  The builder logs every cap it applies.

## USDA FoodData Central

- License: public domain (CC0 1.0). Link: <https://fdc.nal.usda.gov/>
- Used: 67 foods, one FDC id each (`nutritionRef` in `foods.json`), mostly from
  SR Legacy (bulk download `FoodData_Central_sr_legacy_food_json_2018-04`).
  `tomate_arbol` uses FDC 1906026 (tamarillo, branded record) because SR Legacy
  has no tamarillo.
- Substitutions: `leche_deslactosada` uses plain whole milk (FDC 171265), whose
  values for these fields match lactose-free milk.
- Free sugars rule: `none` for whole foods (0), `all` (total sugars) for sugar,
  panela and honey, `added` (added sugars, or total sugars if the source has no
  added sugars) for processed foods (`pan_tajado`, `pasta`, `harina_maiz`).

## Open Food Facts

- License: Open Database License (ODbL) 1.0 for the database, DbCL for its
  contents. Link: <https://world.openfoodfacts.org/> and
  <https://opendatacommons.org/licenses/odbl/1-0/>
- Attribution: nutrition data from Open Food Facts contributors.
- Products used (barcodes of products sold in Colombia):

| Food | Barcode | Product |
| --- | --- | --- |
| `harina_maiz` | 7702020212021 | Harina de Maíz Amarillo Extrafina (Doñarepa) |
| `pan_tajado` | 7705326468727 | Pan Blanco Tajado (Bimbo) |
| `panela` | 7709027205407 | Panela Orgánica (Waiva) |

Requests to Open Food Facts send the identifying user agent from
`scripts/prices/policy.json` and wait one second between calls.

## Not used

- **Colombian Food Composition Table (TCAC, ICBF):** not used until we have
  written permission from ICBF.

## Re-running

```sh
# Fill the extended fields (USDA_API_KEY is optional; DEMO_KEY is ~10 requests/hour,
# so pass the official SR Legacy JSON to avoid the API for most foods)
node --max-old-space-size=4096 scripts/foods/fetch-nutrition.ts --usda-dump <SR Legacy json>
# Regenerate the migration
node scripts/foods/build-seed.ts
```

Tests never use the network: they run against the fixtures in
`scripts/foods/fixtures/`.
