# Price samples (private research)

Small hand-read samples of public shelf prices, used only to **calibrate** the
reference-price catalog of this personal project (for example to check how far
the AI's invented prices are from reality).

- Read on 2026-10-23 from public product/category pages, a few dozen page loads
  at human pace. `robots.txt` was respected (internal search was never used).
- Prices are the *regular* price when the page showed both a regular and a
  promotional price. Promotions are excluded on purpose.
- The city/store was **not** set (it needs an email address on Jumbo and Éxito's
  default applies), so these are default-location prices, not Bucaramanga.
- Ara publishes no online price list.

Before any public launch this approach must be replaced by a legitimate source
(open DANE data, user-contributed prices, or an agreement/feed from the
retailers). Do not redistribute these files.
